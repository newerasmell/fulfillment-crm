# Wave 1 audit (FHB v3, euShipments, API change watcher)

Built by parallel agents in separate worktrees (branches `wave1/fhb`, `wave1/eushipments`, `wave1/api-watcher`), each
reviewed by an independent `auditor` and then fixed by the builder (every CRITICAL/HIGH/MEDIUM finding fixed with a
test, LOW fixed where trivial). Decisions and open questions: `docs/wave-1-notes.md`.
